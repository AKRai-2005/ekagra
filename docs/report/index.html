The problem

Defence, power-grid and classified networks are watched through a data diode: hardware that copies traffic out to a monitoring room and allows nothing back. The sensor there never sees replies, cannot look anything up, and cannot block. Detectors are trained on two-way traffic, so they fail there - and with no return path, nobody can tell them they are wrong.

What we measured, on 877,801 real flows

The loss is not the missing direction. It is missing per-host memory. A sensor that keeps 60 seconds of behaviour per host - peers touched, timing regularity, volume against its own baseline - recovers all of it.

What is missing, and what is next

HONEST LIMITS

Packet-size and timing sequences are not built yet, and the problem statement names them. Dictionary-based DGA domains are weak (AUC 0.69). Evidence integrity depends on a key held in the enclave. 1 Gbps is not reached.

NEXT, IN ORDER

1. Packet-size and timing features. 2. A compiled fast path to line rate. 3. Longer real captures for DNS thresholds. 4. Hardware key custody. 5. Pilot on vendor diode hardware.
